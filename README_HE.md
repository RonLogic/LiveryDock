# LiveryDock 0.4.1 — מתקין צביעות ל־MSFS 2024

[הורדת הגרסה האחרונה](https://github.com/RonLogic/LiveryDock/releases/latest) · [English README](README.md)

## הפעלה מהירה

1. הורד את `LiveryDock-0.4.1-Windows-x64.zip` וחלץ אותו לתיקייה רגילה.
2. פתח את `LiveryDock.exe`. אין צורך להתקין Python עבור גרסה זו.
3. בדוק את נתיבי Community2024 ו־Legacy Community. אפשר לשנות אותם עם Browse.
4. גרור חבילת צביעה לחלון, בדוק את הזיהוי והיעד ולחץ Install selected.
5. להסרה ושחזור הגרסה הקודמת, השתמש ב־Managed Liveries → Uninstall / restore previous. הסר התקנות שחופפות זו לזו בסדר הפוך להתקנה.

קובץ ההרצה אינו חתום. בהפצה כלול קובץ SHA256SUMS.txt לבדיקת שלמות ההורדות.

## תמיכה בפורמטים

- ZIP ותיקיות של חבילות MSFS עם manifest.json ו־layout.json, גם בתוך תיקיית עטיפה.
- RAR ו־7Z באמצעות 7-Zip מותקן.
- PMDG Native 2024 ZIP או תיקייה עם livery.json, livery.cfg, model.airframe וטקסטורות KTX2, גם ללא manifest/layout במקור.
- חבילות ZIP שבתוכן כמה ZIPים של צביעות לאותו מוצר. Common מותקן ראשון, מזהי הצביעות ונתיבי fallback נשמרים.
- PMDG 777-200ER Native, כולל גרסאות GE/RR. אין צורך ב־SDK לצביעות KTX2 מוכנות.
- מסלול PTP של 0.3.1 נשמר: פענוח CRYP/CAB מובנה והמרת DDS ל־KTX2 עבור משפחת PMDG 737 בעזרת ה־SDK הרשמי ותבנית native מתאימה.

נדרשת התקנה של מטוס הבסיס המתאים בגרסת MSFS 2024. הכלי ממיר צביעה, ולא מטוס MSFS 2020 שלם. תאימות לכל קובץ צד שלישי או PTP של FSX/Prepar3D אינה מובטחת.

## התקנת PTP

1. התקן את גרסת MSFS 2024 של מטוס PMDG המתאים.
2. התקן את MSFS 2024 SDK הרשמי. ברירת המחדל היא:

```text
C:\MSFS 2024 SDK\Tools\bin\fspackagetool.exe
```

3. בחר את תיקיית השורש של ה־SDK בשדה MSFS 2024 SDK, אם לא זוהתה.
4. הוסף את קובץ ה־PTP ולחץ Install selected.

הכלי מחלץ את PTP ללא CabLib.dll וללא Operations Center, מזהה את דגם ה־737 והכנפונים, בוחר תבנית native מתוך המטוס המותקן וממיר DDS ל־KTX2. 739ER מזוהה מה־metadata. תבנית או טקסטורה חסרה עוצרות את ההתקנה עם שגיאה.

## יעדים, גיבויים ובטיחות

במצב Auto, חבילות רגילות נשלחות לפי סוגן ל־Community2024 או ל־Community. עבור ZIP של PMDG הכלי מחפש את מטוס הבסיס או חבילת הצביעות בנתיבים שהוגדרו. PTP מותקן ב־Legacy Community שנבחרה.

צביעות PMDG מותקנות בחבילת pmdg-aircraft-*-liveries המתאימה. רשימת layout נבנית מחדש לאחר שינוי. התקנות נבחרות רצות בזו אחר זו כדי לשמור על רשומת ההתקנות והקבצים המשותפים.

הרשומות, הגיבויים והלוג נמצאים ב־`%LOCALAPPDATA%\LiveryDock`. שמור את הגיבויים כדי לאפשר שחזור. אם רשומת ההתקנות נפגמה, שמור עותק שלה ושל הגיבויים לפני טיפול. הלוג עשוי לכלול נתיבים אישיים; בדוק אותו לפני שיתוף.

נתיבי ארכיון מסוכנים וקישורים נדחים. התקנה לתוך Official חסומה. קובצי הרצה וסקריפטים בחבילת PMDG native אינם מועתקים; גם תיקיית Dirty Version האופציונלית אינה מותקנת אוטומטית.

## הפעלה מהמקור ובנייה

נדרשים Windows 10/11 x64 ו־Python 3.11 ומעלה עם Tkinter. פתח את Run LiveryDock.cmd כדי ליצור סביבת עבודה מקומית ולהתקין את התלויות. Build EXE.cmd מתקין כלי פיתוח, מריץ בדיקות ובונה קובץ הרצה וחבילות הפצה.

להוראות פיתוח מפורטות ראה [README באנגלית](README.md). תוצאות הבדיקה בפועל ומגבלות האימות מתועדות ב־[Release validation](docs/RELEASE_VALIDATION.md). בדיקות אוטומטיות משתמשות בקבצים מלאכותיים ואינן מבטיחות הופעה תקינה בסימולטור.

הקוד ברישיון MIT. אין במאגר או בהפצה מטוסים, טקסטורות, חבילות צביעה לדוגמה, DLL של PMDG או סודות. לדיווח תקלה, צרף גרסה, פורמט, שגיאה ושלבי שחזור, ללא קבצים קנייניים.
